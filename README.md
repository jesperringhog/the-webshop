# The Webshop

This is a group project where I collaborated with three teammates to build a fully functional webshop using TypeScript and SCSS.

## Features

- Landing page showcasing featured products
- Product listing page with filtering functionality
- Individual product interactions (add to cart)
- Shopping cart with quantity management and total price calculation
- Persistent cart and product data using localStorage
- Checkout form with required user input validation
- Simulated purchase confirmation flow

## Tech Stack

- TypeScript (Vanilla)
- SCSS
- HTML

Deployment: Vercel

## Installation

Clone the repo:

```bash
git clone https://github.com/jesperringhog/the-webshop.git
cd webshop-godisrattan
```
Then open the project in your browser.

Note: No build step is required unless additional tooling is added.

## Project Structure

- /components   – reusable UI components  
- /data         – initial product data  
- /models       – TypeScript types for products and cart items  
- /pages        – page-specific logic  
- /services     – data handling and state-related logic  
- /styles       – SCSS structure by responsibility  
- /utils        – helper and utility functions
